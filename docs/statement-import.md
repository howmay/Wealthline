# 信用卡帳單匯入（第一版）

在「消費明細」選擇 PDF、輸入解密密碼（若有）、自訂銀行／卡片名稱、帳單月份與金額幣別。PDF.js 在瀏覽器 worker 解密及擷取文字，沒有帳單上傳 API；程式、字元映射與標準字型均由同一網站提供。PDF.js 只在開始解析時載入。

解析後可修改日期、商家、金額及幣別、取消勾選或補上漏掉的交易。核對未辨識列後，確認匯入，再用既有「儲存變更」保存到本機或使用者自己的 Google Drive。消費不會扣除資產，也不會更改負債。

隨部署提供 PDF.js、CMaps 與標準字型的原始授權於 `/third-party/pdfjs/`，版本固定為 6.4.299。

原始 PDF、密碼、完整擷取文字不加入資料檔、不寫日誌。解析完成清除密碼欄位與檔案選擇；取消、換分頁、離開 session 會中止解析。確認的交易及雜湊識別碼才加入財務資料。備份為既有未額外加密的 JSON，勿公開分享。

## 格式範圍

- 文字 PDF，最多 20 MB、100 頁、500,000 字元。
- 交易日期在列首，可為西元／民國完整日期或月／日；第二欄可為入帳日期。沒有年份時，以帳單月份推算跨年。
- 金額在列尾，支援千分位、小數、負號、括號與 CR 退款。已辨識的富邦與玉山臺灣帳單使用最後的臺幣入帳金額，原始外幣金額不另算一筆；匯豐及其他單一金額格式使用指定幣別，臺灣帳單請選 TWD。銀行名稱以檔名或帳單文字辨識，請保留銀行名稱。
- 繳款、上期餘額、應繳總額及多金額不明確欄位不自動匯入。掃描圖片、跨行、垂直文字、复杂外幣布局暫不支援。無交易時顯示失敗；部分辨識時顯示未匯入列，不能將解析筆數當成帳單完整性證明。
- 已以使用者提供的富邦、玉山與匯豐樣本在本機驗證解密與文字解析。富邦支援民國日期與商家後方的入帳日期；玉山支援原幣／臺幣雙金額欄。匯豐樣本缺少商家文字層，只列出雙日期及入帳金額供人工核對，預設不選取，必須補上商家並排除繳款。未加入 OCR，不保證其他月份或版型完整辨識。
- 證券檔名在讀取前直接拒絕；重新命名的檔案也會檢查解密後的證券對帳單特徵。信用卡廣告單獨提及證券不會被拒絕。真實 PDF、密碼與交易內容均不提交；回歸測試只使用合成資料。

## 去重與資料相容

同一張卡請沿用相同名稱。每筆保存 PDF 雜湊＋列序號的來源鍵，以及原始日期／商家／金額／幣別／卡片名稱＋同值出現序號的交易鍵。兩者都雜湊後保存，修改預覽或已匯入交易仍保留原始識別碼。確認時再次比對識別碼及修改後交易內容；相同值的多筆交易依出現次數保留。沒有銀行交易編號時，兩張不同帳單上完全相同的獨立交易仍可能被當成重複，請核對預覽。

加入消費後升為資料格式 v10，讀取仍支援 v1–v9；其他資產／歷史操作及背景儲存保留 v10 與消費資料。舊版客戶端會拒絕讀取 v10，避免不知情地刪掉消費資料。

驗證包含合成交易的日期、退款、排除繳款、去重、編輯後重匯入、同值多筆、無效整批拒絕、資料往返與版本保留。加密 PDF 合成樣本的密碼為 `fixture-password`，僅供測試。
