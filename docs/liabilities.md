# 負債管理與貸款試算

## 行為與資料格式

負債獨立於資產帳戶，以 `liabilities` 陣列儲存。每筆包含 `id`、名稱、類型、幣別及非負的 `balance`；0 代表目前無欠款。類型為房貸、信貸、信用卡與其他。

新增貸款預設本息平均攤還，只需目前剩餘本金、年利率（百分比）及剩餘月數。可改成本金平均攤還，或選「只記錄餘額／不試算」處理信用卡、寬限期及不規則還款。日期與備註選填。試算條件使用 `repaymentMethod`、`annualRate`、`remainingInstallments`；不儲存衍生還款表。

既有 `paymentAmount`、`totalInstallments`、`paidInstallments` 手填值仍可讀取、保留並顯示，不再要求重複輸入。不替舊資料選擇攤還方式或由總期數推定剩餘期數；未指定方式時不試算。每期應付不等於實際未償本金。此功能沒有自動扣款、銀行串接、提醒或收據匯入。

## 試算公式與限制

依[土地銀行還款試算說明](https://www.landbank.com.tw/Calculate/Repayment)：設目前本金為 P、剩餘月數為 n、月利率 r = 年利率百分比 / 1200。本息平均攤還每月應付 A = P × r / (1 − (1+r)^−n)，當 r = 0 時為 P/n。本金平均攤還每月本金 P/n，利息為期初餘額 × r，應付隨本金餘額降低；0% 時不變。介面分開呈現固定月付與首末期應付。

假設每月繳款、利率固定、沒有寬限期、提前還款及費用。銀行按日計息、利率調整及捨入方式可能不同，因此僅供估算。試算顯示每期本金、利息、應付、期末本金與剩餘總利息；不會隨日期改寫實際餘額或淨資產，實際還款後請自行更新本金與剩餘期數。

期數限 1–1200 整數（最多 100 年），每頁 12 期。運算不逐期捨入，使用 log1p/expm1 改善極小利率與長期數的穩定性，補償加總利息並在最後一期結清剩餘本金。顯示小數 2 位，各欄獨立四捨五入，可能有顯示尾差；超出有限數值範圍時拒絕套用試算條件。

總負債依既有匯率換算為 TWD；淨資產 = 總資產 − 總負債，允許為負。任何非零資產或負債缺少有效匯率時，不呈現不完整的淨資產。已清償的零餘額不因缺少匯率變成未知負債。

表單套用只更新記憶體，仍需「儲存變更」。刪除需明確確認；確認視窗可復原新增、修改或刪除的負債。取消表單不改資料；取消儲存確認保留已套用但未儲存的修改。

## 相容與歷史

- 可載入 v1 JSON，負債不存在時視為尚未記錄。
- 新資料及儲存後格式為 v2。既有 v1 客戶端重新載入時會拒絕解析 v2，因此可防止它讀入 v2 後靜默丟棄負債欄位。不能把新版檔案直接降版給舊客戶端使用。
- 版本欄位不是跨客戶端的寫入鎖，不能保證已開啟的舊分頁不覆寫資料。已載入 v1 的分頁仍可嘗試儲存：包含條件寫入修復的版本依賴 Drive 的 `If-Match`（真實原子性仍待驗證）；更早的無條件寫入版本仍可能覆蓋 v2 資料。
- v2 的 `liabilities` 必須是陣列，識別碼不得重複；數值必須有限且非負。期數必須是有效整數，已繳期數不得超過已知總期數；日期必須有效。
- 既有 `history.changes` 保持資產口徑；負債新增 `history.liabilityChanges`，保存完整修改前後狀態，包含名稱、幣別與選填欄位。
- 快照 `total`、帳戶及類別仍只代表資產，原資產圖不扣負債。另新增 `liabilityTotal` 與 `netWorth`；欄位不存在表示「未記錄」，null 表示「無法換算」。不重建未知的過去負債。
- 僅有負債也能記錄每日快照；刪除最後一筆負債會記錄為 0，避免歷史持續沿用舊餘額。
- 資產試算表匯入不修改負債。沿用既有 Drive 條件寫入與同步鎖，儲存等待期間的新負債修改／刪除仍保留且維持 dirty。

## 驗證

所有 fixture 均為自行建立的合成資料，不含個人財務文件的金額或識別資訊。

```sh
npm test
npm run lint
npm exec tsc -- -b
npm run build
git diff --check
```

回歸涵蓋負債新增、編輯、取消、刪除、復原、零餘額、負淨資產、多幣別、缺失匯率、v1→v2、舊快照未知值、獨立負債異動、刪除最後一筆，以及每日快照寫入期間修改負債。另涵蓋兩種攤還公式、零利率、零本金、單期、1200 期、極小利率、數值溢位、分頁與舊手填資料保留。React 操作測試使用 jsdom；另以本機 Chromium 及模擬 Drive 檢查手機／桌面版面，不連接 Google 帳戶。

本次沒有新增遠端部署或 CI。真實 Drive `If-Match` 原子性與 CORS 的原有待驗證事項仍見 [資料安全驗證紀錄](data-safety-validation.md)。
